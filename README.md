# reuseart

Minimal single-page fine art portfolio site built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — page structure and artwork content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation, reveal animation, and nav scroll state
- `images/` — place your artwork files here (`art1.jpg`, `art2.jpg`, `art3.jpg`)

## Replace placeholder artwork

1. Add your real image files to `/images` and keep or update the paths in `index.html`.
2. Replace each artwork block title, medium, year, dimensions, and description in `index.html`.
3. Keep `loading="lazy"`, image `width`/`height` attributes, and descriptive `alt` text for performance and accessibility.

## Local preview

Open `index.html` directly in a browser, or serve the folder with a static server.

## GitHub Pages deployment

1. Push this repository to GitHub.
2. In repository settings, enable **Pages** and set source to the default branch root.
3. The site will be published as a static single page.
